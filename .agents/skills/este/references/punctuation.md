# Puntuación para la claridad

ESTE usa la puntuación para forzar una sola lectura, no para adornar la prosa.

## Prefiere

| Signo            | Uso                                                          |
| ---------------- | ------------------------------------------------------------ |
| `.`              | Cierra una idea; empieza la siguiente                        |
| `,`              | Listas ligeras o incisos que no ocultan la oración principal |
| `:`              | Introduce una lista o una definición                         |
| `¿?` / `¡!`      | Solo cuando el acto de habla es realmente pregunta o alerta  |
| Listas numeradas | Procedimientos con 3 o más pasos                             |
| Viñetas          | Condiciones u opciones en paralelo                           |

## Evita o limita

| Signo               | Guía                                                                        |
| ------------------- | --------------------------------------------------------------------------- |
| `;`                 | Prefiere dos oraciones (ESTE-007)                                           |
| `...`               | No uses puntos suspensivos para omitir constituyentes necesarios (ESTE-008) |
| Raya / inciso largo | Suele indicar que conviene separar la oración                               |
| Paréntesis apilados | Pasa las condiciones a oraciones `si` / `si no` (ESTE-024)                  |
| `/` entre sinónimos | Elige un término (ESTE-001)                                                 |

## Listas

Bien:

```markdown
1. Abre el panel de servicios.
2. Selecciona `api-gateway`.
3. Pulsa Reiniciar.
```

Mal: las mismas tres acciones dentro de una sola oración larga.

## Comillas y código

- Usa backticks para etiquetas de UI, comandos e identificadores: `Guardar`, `api-gateway`.
- No inventes puntuación alrededor del código que cambie el significado.
