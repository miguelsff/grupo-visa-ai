# Principios de ESTE — v0.1

ESTE (Español Técnico Simplificado) es un estilo controlado para español
técnico. Estos principios rigen todas las reglas de `rules.md`.

## Propósito

Los lectores (personas o agentes) deben poder:

1. Obtener la información que necesitan
2. Encontrarla sin buscar entre ruido
3. Comprenderla en la primera lectura
4. Usarla sin adivinar la intención del autor

Estos cuatro resultados siguen los principios de lenguaje claro de
UNE-ISO 24495-1, aplicados al español técnico (no a la comunicación general
al público).

## Postura de diseño

| Postura                         | Significado                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Claridad antes que elegancia    | Prefiere español plano y literal                                                                                 |
| Consistencia antes que variedad | Los sinónimos son un error si nombran el mismo concepto                                                          |
| Precisión antes que brevedad    | Más corto solo si el significado se mantiene intacto                                                             |
| Evidencia antes que pulido      | No inventes hechos para que la oración quede más limpia                                                          |
| Español primero                 | Prefiere términos españoles compartidos; conserva inglés de dominio solo si el equipo ya lo usa de forma estable |

## Qué no es ESTE

- **No es Lectura Fácil (UNE 153101).** Público y método distintos.
- **No es ASD-STE100 certificado.** Se inspira en su estructura; no redistribuye su diccionario.
- **No es una guía de creatividad.** Marketing y voz narrativa quedan fuera de alcance.
- **No es un corrector ortográfico.** La ortografía sigue RAE/ASALE; ESTE se centra en ambigüedad y consistencia.

## Origen de las reglas

Cada regla nuclear cita uno o más de:

| Código     | Fuente                                     |
| ---------- | ------------------------------------------ |
| `STE`      | Práctica estructural de ASD-STE100         |
| `ISO24495` | Principios/directrices UNE-ISO 24495-1     |
| `ES`       | Patrones de ambigüedad propios del español |
| `ESTE`     | Criterio propio del proyecto               |
