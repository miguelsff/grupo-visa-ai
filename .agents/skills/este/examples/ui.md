# Ejemplos de copy de UI

## Ayuda de botón

**Antes**

> Al hacer clic en este botón se procederá al guardado de los cambios realizados en el formulario actual.

**Después**

> Guarda los cambios del formulario.

## Estado vacío

**Antes**

> Todavía no hay elementos que mostrar en este momento. Puedes comenzar creando uno nuevo cuando lo desees.

**Después**

> No hay elementos. Crea el primero.

**Después**
